# Amethisty

Amethisty is an Android mod-loader project for Geometry Dash 2.2091.

## Project status

**Early development.** The repository now has the initial package-format proposal and native mod API skeleton. It is not yet installable or ready to compile as a complete loader.

## Planned features

- Android native loader for Geometry Dash 2.2091
- In-game mod management
- Dedicated `.amethyst` mod package format
- Native mod API and developer SDK

## Development approach

Amethisty uses GD Mod Example Android and Android-ML as technical bases. Their original license notices and required attribution must be preserved for any reused code or files. The project will be adapted and integrated rather than assuming either base already supports Geometry Dash 2.2091.

Development happens in this repository. Builds and device testing are performed manually.
